# Cierre

Ver tambien: [indice](./README.md), [roles](./ROLES.md), [juegos](./RULETA.md), [presupuesto](./PRESUPUESTO.md), [tesoreria](./TESORERIA.md) y [director](./DIRECTOR.md).

Principio: el viaje no termina cuando se vuelve, termina cuando nadie debe nada y ya se hablo de como salio.

## Cuentas finales

El [tesorero](./ROLES.md#tesorero) cierra Spliit con el manual de [tesoreria](./TESORERIA.md), cobra lo que falte y nadie queda debiendo. Cada gasto quedo apuntado en el viaje, asi que el cierre es solo cobrar saldos.

## Retro

La dirigen [actividades](./ROLES.md#actividades) y [director](./ROLES.md#director) con el manual de [director](./DIRECTOR.md). Dos preguntas y queda escrito: que se repite y que se cambia para el proximo.

## Proxima semilla

La idea del proximo viaje (destino o plan) se elige entre todos con una dinamica. Si hay que rifar entre opciones, se usa la [ruleta](./RULETA.md#ruleta) y el resultado se anota.
