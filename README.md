# NT Trip 2026: blueprint de viajes

Sistema del grupo para planear cualquier viaje con los mismos pasos. Principio rector: **los 5 primero**.

## Como funciona

Tres pasos y un ejemplo.

1. Reparte los 7 roles. Somos 5 personas y hay 7 roles, asi que 2 llevan doble rol. Lee [los 7 roles](./ROLES.md).
2. Cada quien lee su manual. El tesorero lee tesoreria, el chef lee chef, y asi. Cada manual dice que hacer antes, durante y cierre.
3. Viaja con el sistema y cierra en ceros. Todo gasto se apunta al momento, todo acuerdo queda en la bitacora, al final nadie debe nada.

Ejemplo: viaje de 3 dias. Antes se reparten roles y se fija el tope. Durante, cada quien hace su parte y apunta todo. Al cierre se cobran saldos, se hace la retro y queda la semilla del proximo. Detalle en [cierre](./CIERRE.md).

## Orden de lectura

Si es tu primera vez, lee en este orden.

1. Reglas base (todos): [roles](./ROLES.md) y [ruleta](./RULETA.md).
2. Tu manual (solo el tuyo): busca tu rol en el mapa de abajo.
3. Herramientas (cuando las necesites): [presupuesto](./PRESUPUESTO.md), [Spliit](./SPLIIT.md), [tesoreria](./TESORERIA.md) y [bitacora](./BITACORA.md).

Si solo te toco un rol, con las reglas base y tu manual basta para empezar.
